# ちきちきパズルズ

2006年から2009年にNTTドコモのiアプリとして作った3つのパズルゲームを、2026年のWeb技術で再構築したインストール可能なPWAです。

- **おーとまちっく数独**: 唯一解を保証した問題生成、右クリック候補メモ、Undo、ヒント、任意の同数字ハイライト、複雑度評価付き4段階の難易度
- **ちきちきまいんすいーぱ。**: 初手安全、右クリックによる旗・?・解除の3段階マーカー、周囲の一括展開、連鎖スコア、踏んだ地雷の識別、3段階の盤面、論理だけで完走できる推測不要モード
- **四川省**: 2回以内に曲がる経路探索、必ず解ける配牌、経路アニメーション、牌ズーム、クリア後の初期盤面閲覧、mobility評価付き3段階の難易度

トップURLには3ゲームを選べるタイトル画面を表示します。全ゲームでseed付きURLとQRコードによる盤面共有、終了時のSNS共有、開始カウントダウン、成績画面、難易度変更前の確認、4つのカラーテーマ、生成BGM、効果音、音量調整に対応しています。BGMは静かな音色を保ちながら、100%では十分に聞き取れるゲインへ調整しています。画面上の操作要素には説明ツールチップがあり、既定OFFのマウスマーカーと追加アニメーションは個別に切り替えられます。ダイアログは盤面より前面に固定されます。

マインスイーパの推測不要モードは、公開済みの数字から安全マスと地雷を確定するソルバーで候補盤面を検証し、最後まで論理的に解ける盤面だけを採用します。OFFにすると初手と周囲だけを安全にしたクラシック配置へ戻ります。共有URLにはseed、初手、生成モードを含め、同じ地雷配置と初期展開を再現します。

## 公開サイト

[https://kenrouse.github.io/chikichiki-puzzles/](https://kenrouse.github.io/chikichiki-puzzles/)

初回アクセス後はオフラインでも遊べます。ゲームの進行、設定、記録はブラウザーのローカルストレージにのみ保存し、外部へ送信しません。

## 技術構成

- React 19 / TypeScript 6 / Vite 8
- `vite-plugin-pwa` / Workbox
- Web Audio API / `qrcode.react`
- Vitest
- GitHub Actions / GitHub Pages

ゲームルールはUIから独立した純TypeScriptとして実装し、同じseedから同じ盤面を再現できるようにしています。

## 開発

Node.js 24以降とnpm 11以降を使用します。

```powershell
npm ci
npm run dev
```

検証コマンド:

```powershell
npm run lint
npm test
npm run build
```

本番ビルドはGitHub Pagesのプロジェクトパス `/chikichiki-puzzles/` を基底URLとして生成されます。
