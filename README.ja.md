# ちきちきパズルズ

[English](./README.md) | **日本語**

2006 年から 2009 年に NTTドコモの iアプリとして作った 3 つのパズルゲームを、インストール可能な PWA として再構築しました。

[![ちきちきパズルズのタイトル画面](./docs/assets/20260812_chikichiki-puzzles.png)](https://kenrouse.github.io/chikichiki-puzzles/)

## プレイ

**[ちきちきパズルズを開く](https://kenrouse.github.io/chikichiki-puzzles/)**

初回アクセス後はオフラインでも遊べます。ゲームの進行、設定、記録はブラウザーのローカルストレージにのみ保存し、外部サービスへ送信しません。

## ゲーム

- **おーとまちっく数独**: Algorithm X / Dancing Links で一意解を検査するクラシック数独、手筋と rating の目標で選ぶ 5 段階、確定／メモ入力、元に戻す、ヒント、候補ガイド、同じ数字の強調に対応します。対称と Killer の生成ロジックは、ゲーム性を調整する間、設定から明示的に有効化するプレビュー機能として残しています。
- **数独からの挑戦状**: エキスパート10,000候補を事前評価し、RATING 1,000以上だけを収録した163問を盤面プレビューとRATING帯フィルターから選べます。
- **ちきちきまいんすいーぱ。**: 初手安全、ゲーム設定から選べる推測不要／クラシック生成、タッチ用の開く／マーク切替、右クリック／長押しによるマーク、ドラッグ誤操作防止、画面に合わせる倍率、連鎖スコア、ベストスコア／タイム、実際の地雷と踏んだ地雷を区別する表示に対応します。
- **四川省**: 2 回以内に曲がる経路探索、必ず解ける配牌、経路アニメーション、手動ズームと画面に合わせる倍率、クリア後の初期盤面閲覧、mobility 評価による 3 段階に対応します。

## 主な特徴

- seed 付きの決定的な問題生成と、URL、QR コード、Web Share、コピーによる共有。
- アプリ UI、遊び方、ARIA ラベル、ダイアログ、制作ノートの日本語／英語対応。
- マウス、タッチ、ペン、キーボード入力、明確なフォーカス表示、動きを減らす設定への対応。
- ローカル保存と再開、オフライン PWA、4 つのカラーテーマ、生成 BGM、効果音、個別音量調整。
- 全画面／集中モード、画面に合わせる盤面倍率、明示的なランク条件、結果画面の次ランク目標。
- 新しい問題は開始を確定した時点で生成し、不透明な 3 秒カウントダウンで覆うため、開始前に盤面が見えません。保存済みゲームはカウントダウンなしで再開します。
- 可視ラベルとツールチップの役割を分離し、文字付き操作には必要な補足だけを表示し、アイコンのみの操作には短いアクセシブル名を残しています。

## 言語対応

アプリは日本語と英語を正式にサポートします。このファイルは日本語版で、リポジトリの既定入口となる英語版は[README.md](./README.md)です。

コードの識別子と API は英語で統一しています。詳細な技術文書は現在、[`docs/`](./docs/README.md) の日本語を正本として保守しています。正式版がない言語では、ブラウザー翻訳を補助として利用できます。

## 技術構成

- React 19 / TypeScript 6 / Vite 8
- `vite-plugin-pwa` / Workbox
- Web Audio API / `qrcode.react`
- Vitest / ESLint
- GitHub Actions / GitHub Pages

ゲームルールと生成エンジンは React UI から独立した純 TypeScript として実装し、同じ seed と生成条件から同じ盤面を再現できます。

## 開発

Node.js 24 以降と npm 11 以降を使用します。

```powershell
npm ci
npm run dev
```

検証コマンド:

```powershell
npm run lint
npm test
npm run build
```

新しい版の挑戦状カタログを現在の数独生成器から作成する場合:

```powershell
npm run generate:sudoku-challenges -- --catalog=YYYYMMDD-v1
```

公開済みカタログは共有URLを維持するため上書きせず、新しい版を追加します。

本番ビルドは GitHub Pages のプロジェクト パス `/chikichiki-puzzles/` を基底 URL として生成します。
