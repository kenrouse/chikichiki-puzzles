# Roadmap

この文書は、会話と設計検討で挙がった未実装候補を整理するためのものです。優先順位、期限、実装の確約を表すものではありません。着手を決めた項目はGitHub Issueへ移し、受け入れ条件と検証方法を定義します。

## 後続実装へ分離した要件

### 開始操作と盤面中央への自動スクロール

ゲームを開いただけでは移動せず、明示的な開始ボタンで盤面を中央へスクロールしてカウントダウンを始める案です。開始前に設定を確認できる利点があります。v1.3.0で集中／全画面実装とは分離し、現行は画面上部へ移動するだけで盤面中央への自動スクロールは行いません。

### タッチ用の「開く／マーク」切替

マインスイーパで長押し中に指が盤面を隠す問題への代替案です。画面下部のスティッキー切替でタップ動作を選び、長押しをショートカットとして残します。現行はスワイプ誤操作防止とタッチ／ペン長押しまでで、明示的なマークモードはありません。

## 発展案

### 画面に合わせる倍率

現在の表示領域から適切な盤面倍率を計算するボタンです。現行は集中／全画面と手動ズームを採用し、自動フィットは未実装です。

### 数独の人間向け高度手筋評価

ロック候補、裸／隠れペア、X-Wing、XY-Wing、連鎖を段階適用し、使った最も高度な手筋と適用回数で難易度を分類する案です。現行ratingは、裸／隠れシングル後の未解決数とバックトラック探索量を使います。

### 数独生成器の拡張

Algorithm X / Dancing Linksによる一意解判定、回転対称な最小問題、Killer Sudokuの和制約を追加する案です。いずれも制作ノート上の将来案で、現行要件ではありません。
