# Roadmap

この文書は、会話と設計検討で挙がった未実装候補を整理するためのものです。優先順位、期限、実装の確約を表すものではありません。着手を決めた項目はGitHub Issueへ移し、受け入れ条件と検証方法を定義します。

## 現在の候補

新規生成と盤面中央スクロール、タッチ用の開く／マーク切替、画面に合わせる倍率、人間向け数独手筋評価、Algorithm Xは実装済みです。

### 数独の対称／Killerプレビュー評価

対称とKillerは生成・プレイ可能なロジックを残し、設定画面で明示的に有効化した場合だけ表示します。正式な標準UIへ戻す前に、次を評価・改善します。

- 対称: 180度対称とペア最小が見た目以外のゲーム性を生むか、クラシックと難易度差を体感できるか、5段階のratingと手筋分布が適切かを確認する。
- Killer: 与え数字を残す現行形式と一般的なKiller Sudokuの差を評価し、ケージ構成、合計推論、ヒント、候補ガイド、競合表示、難易度ratingを一体として調整する。
- 共通: 代表seedと広いseed標本で一意解、生成時間、難易度の順序、極端な盤面を検査し、初見プレイテストでルール理解と楽しさを確認する。
- 正式公開条件: タイプ固有の遊び方が明確で、クラシックとは異なる選択価値があり、入門からエキスパートまで難易度が安定していることを、テストと実プレイの両方で確認する。
